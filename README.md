# Tile and Object Markers

Tile indicators, persistent ground markers, and persistent object markers for RuneLite, all with labels.

## Features

### Tile Indicators
- Highlights your true tile, destination tile, and hovered tile.
- Destination highlight has its own toggle (on by default).
- All highlights support corner style, borders, custom colours, opacity, and border width.
- True tile can fade out after you arrive.

### Ground Markers
- Hold the mark key (default Ctrl) and right-click to mark tiles.
- **Mark Tile** — marks a single tile.
- **Mark Region** — click one corner, then the opposite corner to fill a rectangle.
- **Mark Border** — same as region but only the perimeter.
- **Unmark** options to remove a single tile, whole region, or whole border.
- **Merge borders** draws touching tiles as one shape (can be toggled per style).
- Labels can be added via the right-click menu or side panel.

### Object Markers
- Uses the same mark key. Right-click an object to mark it.
- Supports Outline, Hull, Tile, and Clickbox highlights (can be combined).
- Labels, name display, and left-click text options.
- Per-object colour overrides.

### Side Panel
- Separate tabs for Tiles and Objects, each with a list and groups view.
- Create and manage groups. New marks can automatically join the active group.
- Filter between Ungrouped, Grouped, or Show all.
- Quick delete toggle shows an X on each marker.
- Copy/import groups.
- Per-group colour, corner, and merge settings.
- Hiding the sidebar icon does not disable the plugin.

### Other
- Minimap markers (off by default).
- All markers, labels, and groups persist across logout, world hop, and client restart.
- Drawing overlays below the player or NPCs requires the GPU plugin.
